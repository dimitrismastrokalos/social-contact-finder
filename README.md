# 🔍 Social Media Contact & Profile Finder (Python + Playwright)

A lightweight OSINT & lead generation tool designed to extract public social media profiles and contact information based on target keywords and locations.

---

## 🚀 Lite Version Features

- 🎯 **Targeted Search:** Finds public profiles on LinkedIn, Instagram, X (Twitter), and Facebook using search dorks.
- 📝 **Snippet Extraction:** Extracts bio summaries, titles, and profile links.
- 💾 **CSV Export:** Saves leads cleanly into `social_leads.csv`.
- ⚡ **Headless Execution:** Powered by Playwright for speed and reliability.

---

## ⚙️ Installation & Usage

1. Clone this repository
git clone [https://github.com/dimitrismastrokalos/social-contact-finder.git](https://github.com/dimitrismastrokalos/social-contact-finder.git)
cd social-contact-finder

2. Install dependencies
pip install -r requirements.txt
playwright install

3. Run the finder
python main.py
